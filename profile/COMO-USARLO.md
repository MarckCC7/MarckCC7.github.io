# README de perfil de GitHub

`README.md` de esta carpeta va copiado tal cual al repositorio
**`MarckCC7/MarckCC7`** (el repo que se llama igual que el usuario). GitHub lo
renderiza automáticamente en https://github.com/MarckCC7

## Por qué vive aquí y no solo allá

El banner que encabeza el README es
`https://marckcc7.github.io/profile-banner.svg`, un archivo de **este** repo.
Manteniendo los dos juntos, el día que cambies los colores del sitio el banner
cambia con él, y no hay que recordar dónde estaba.

Es un SVG animado propio en lugar de un generador de terceros
(readme-typing-svg, github-readme-stats y compañía): esos servicios se caen,
se rate-limitan y cambian de API — y cuando pasa, tu perfil aparece con una
imagen rota y tú te enteras semanas después.

## Al actualizarlo

Si cambias proyectos, stack o experiencia en `src/data/`, este README **no se
actualiza solo**. Son dos repos independientes. Repasa que sigan coincidiendo.

## Nota sobre las insignias

Las de tecnologías vienen de shields.io. Es el estándar de facto y es fiable,
pero sigue siendo un tercero: si algún día no cargan, no es culpa tuya.

Deliberadamente **no** hay tarjeta de estadísticas de GitHub. Con pocos repos
públicos, esa tarjeta juega en tu contra: enseña números bajos justo donde
quieres que lean tus proyectos. Cuando tengas actividad sostenida, se añade en
una línea.
